Top 5 Hacker News Stories

Live from Hacker News, with an industry-relevance summary for each story.

This page fetches the current top 5 stories from Hacker News and, for each one, asks Google's Gemini to infer the industry it's most relevant to and explain why it matters for that industry.

Everything runs from a small local Node server — the Hacker News API needs no credentials, and Gemini calls happen server-side so no API key ever reaches the browser.
